# Dog Social Network — POC

Prova de conceito de uma rede social voltada a cães, construída com Next.js. O projeto explora páginas e componentes para uma experiência social temática.

## Stack
- Next.js
- React
- TypeScript

## Como executar

```bash
npm install
npm run dev
```

Acesse http://localhost:3000. Para compilar, use `npm run build`.
